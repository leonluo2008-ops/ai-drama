## 方法1：Prompt分层架构

### 核心思路
将prompt分为三层，避免逐格重复全局信息：

```
第一层（全局声明，写一次）：
  - 环境设定：场景 + 氛围 + 光影基调
  - 角色设计：外观全称（从角色卡继承）
  - 画幅 + 排列：宫格布局 + 每格比例

第二层（逐格描述，只写差异）：
  - Panel N (景别/叙事功能)：该格独有的画面内容

第三层（尾部追加）：
  - 风格修饰词：技术增强词（与全局风格锁定一致）
```

### 对当前Skill的改进
- ❌ 当前：每格重复完整角色外观（浪费token，增加漂移风险）
- ✅ 改进：全局声明一次角色，逐格只描述动作/表情/镜头变化

### 示例（不要照搬，学结构）
```
A 3-panel horizontal storyboard, each panel 16:9.
Global: A black ant with glossy chitin shell. Sunlit green meadow, warm golden side-backlighting.
Panel 1 (close-up): standing on orange leaf, antennae raised.
Panel 2 (medium): marching with 3 others on dirt path.
Panel 3 (wide): ant hill mound from above.
Style: Ghibli illustration, hand-painted texture. No text.
```

## 方法2：叙事行分组

### 核心思路
分镜不是"第1格第2格"的线性排列，而是按**叙事功能**分组：

| 叙事阶段 | 功能 | 典型景别 |
|---------|------|---------|
| 起势（铺垫） | 建立环境、引入角色 | 远景→中景→推进 |
| 冲突（爆发） | 动作/对话/转折 | 特写→快切→反应 |
| 余韵（收束） | 情绪沉淀、定格收尾 | 全景→细节→定格 |

### 对当前Skill的改进
- ❌ 当前：按"对话/动作/情感"分类镜头，与叙事脱节
- ✅ 改进：按叙事功能分组，每组内有明确的镜头推进逻辑

### 适用场景
- 3格：起势1格 + 冲突1格 + 余韵1格
- 6格（2×3）：每行一个叙事阶段，每阶段2格
- 9格（3×3）：每行一个叙事阶段，每阶段3格
- 格数不固定：按叙事需要分配，不是均分

## 方法3：每格描述精简格式

### 核心思路
每格只保留**不可省略**的信息，其他由全局声明覆盖：

```
Panel N (景别/叙事功能)：画面描述
```

### 当前Skill的字段对比

| 字段 | 当前Skill | 改进后 |
|------|----------|--------|
| 画面 | ✅ 保留 | ✅ 保留 |
| 光影 | 单独字段 | 合并入全局声明 |
| 色调 | 单独字段 | 合并入全局声明 |
| 氛围 | 单独字段 | 合并入全局声明 |
| 连贯性 | 单独字段 | 简化为"上一帧→本帧" |
| 景别 | 单独字段 | 合并入Panel标题 |
| 运镜 | 单独字段 | ✅ 保留（影响画面） |
| 角色外观 | 每格重复 | 全局声明一次 |

### 效果
- Prompt更短（控制在150词以内更稳定）
- 全局信息不漂移（只写一次）
- 逐格描述更聚焦（只写该格独特内容）

---

## 总结：三条方法论的关联

```
方法1（分层架构）解决 "prompt怎么组织"
方法2（叙事分组）解决 "镜头怎么编排"
方法3（精简格式）解决 "每格写什么"
```

三条方法共同作用：
1. 先用方法2确定叙事结构和镜头编排
2. 再用方法1的分层架构组织prompt
3. 最后用方法3的精简格式填写每格内容
