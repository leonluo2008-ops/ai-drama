# 角色差异化设计方法论

> 同一参考图无法生成多个差异化角色——AI图生图是"复刻"不是"创作"。本方法论解决：如何用有限参考图生成多个不同角色。

## 核心问题

**同一参考图生成多个角色，结果必然相同或高度相似。**

原因：参考图驱动的是「物种+风格+核心特征」，图生图会继承参考图的所有视觉元素，包括颜色、配饰等差异化维度。

## 角色差异化维度

| 维度 | 示例 | 能否靠参考图继承 |
|------|------|----------------|
| 物种 | 鸭子 vs 兔子 | ❌ 需独立参考图 |
| 风格 | 写实 vs 卡通 | ✅ 可继承 |
| 服装颜色 | 黄色安全帽 vs 蓝色安全帽 | ❌ 需独立参考图或差异化prompt |
| 面部特征 | 眼睛颜色、发型 | ❌ 需独立参考图或差异化prompt |
| 配饰 | 安全帽 vs 棒球帽 | ❌ 需独立参考图 |

## 可行的角色拓展方案

### 方案A：每个角色独立参考图（推荐）

```
{角色A}参考图 → {角色A}角色图
{角色B}参考图 → {角色B}角色图
```

**优点**：最可靠，差异化明确
**缺点**：需要用户或创作提供多张参考图

### 方案B：独立文生图 prompt

```
{角色A}：{物种}+{颜色}+{配饰描述}
{角色B}：{同物种}+{不同颜色}+{不同配饰描述}
```

**注意**：需要 prompt 锚定风格，否则两个角色可能风格不一致
**示例**：
```
{角色A}：minion style male, yellow skin, black short hair, brown eyes...
{角色B}：minion style male, yellow skin, ORANGE hair, GREEN eyes...（差异化）
```

### 方案C：手动编辑参考图

用 PS/图像编辑工具把参考图中的配饰颜色/样式改成另一个版本，作为第二个角色的参考图。

**示例**：{角色A}配饰颜色X → PS改成差异化版本 → 作为{角色B}参考图

**优点**：保持风格完全一致
**缺点**：需要人工介入

### 方案D：不同物种 + 同一风格

```
{角色A}：{物种A}+{服装描述}
{角色B}：{物种B}+{同服装描述}  → 不同物种自然差异化
```

**优点**：差异化明显
**缺点**：不一定符合故事设定

### 方案E：参考图+差异化prompt（脚本已支持）

```
{角色A参考图} + face_prompt="{差异化元素X}" → {角色A}
{角色A参考图} + face_prompt="{差异化元素Y}" → {角色B}
```

参考图驱动风格一致性，face_prompt 驱动差异化。
适用场景：参考图已确定物种+风格，只需差异化某个具体元素。

## 决策树

```
收到多个角色的生成需求
  ↓
用户提供了 N 张独立参考图？
  ↓ 是 → 每个角色用各自的参考图（方案A）
  ↓ 否
    ↓
  能否找到同风格的参考图？
    ↓ 是 → 参考图 + 差异化 face_prompt（方案E）
    ↓ 否
      ↓
    是否有明确的风格锚定（如 minion style）？
      ↓ 是 → 方案B：文生图 + 风格锚定 + 差异化 prompt
      ↓ 否
        ↓
      能否手动编辑参考图？（方案C）
        ↓ 是 → 方案C
        ↓ 否
          ↓
        不同物种是否可行？（方案D）
          ↓ 是 → 方案D
          ↓ 否 → 返回用户：需要更多参考图或明确差异化要求
```

## 脚本能力（已支持）

`dreamina_generate.py` **已支持** `face_image + face_prompt` 组合：

```bash
python scripts/dreamina_generate.py \
  --type character \
  --project "{项目名}" \
  --character "{角色名}" \
  --face_image "/path/to/参考图.png" \
  --face_prompt "{差异化描述}" \   # ← 驱动差异化
  --outfit_image "/path/to/参考图.png"
```

- `face_image` 驱动风格一致性（物种、体态、画风）
- `face_prompt` 驱动面部差异化（配饰颜色、发型等）

## 经验规则

1. **同一参考图 = 同一角色**：不要期望 AI 自动对同一参考图做差异化处理
2. **风格锚定 > 自由发挥**：文生图时明确风格词（如 minion style）比不加风格词更可靠
3. **配饰颜色是最容易的差异化**：发型/眼睛颜色容易被风格吞噬，配饰颜色更稳定
4. **差异化越具体越可靠**：「橙色头发」比「不同发型」更稳定，因为描述更具体
