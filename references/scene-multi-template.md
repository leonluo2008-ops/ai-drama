# 场景多角度 Prompt 模板

## 用途
场景多角度参考图生成时使用。脚本从本文件加载内容，组织后提交给 Dreamina。

## 模板内容

### 必须包含的四个视角
1. 左上：平视中景，展示家具高度与空间尺度
2. 右上：仰视天花板/顶部，展示顶部建筑设计与灯光细节
3. 左下：近景特写，展示材质纹理与道具细节
4. 右下：俯视鸟瞰，展示空间平面布局与动线

### 约束条件
- NO HUMANS NO CHARACTERS，禁止出现任何人物
- 不要出现任何文字
- 保持与原图一致的色调与光影风格

### 调用方式
```python
# 脚本加载本文件内容，组装成图生图 prompt
# 图片1 = 场景大图（source）
# prompt 结构：四个视角描述 + 约束条件
```
