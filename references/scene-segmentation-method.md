# 场次切分方法论（台词量优先）

> 来源：2026-05-20 实测教训 + 会话整理
> ⚠️ 以下是方法论，不是硬模板。每场时长必须落在Seedance约束内（4-15秒），按实际台词量计算。

---

## 核心原则

**场次划分是导演/AI的职责，不是编剧的职责。**
编剧按叙事需要写剧本，导演按此方法论切分场次。

**一个场次 = 一个Seedance生成单元（4-15秒）。**

---

## 切分公式（动态时长）

```
步骤1：统计本场所有台词字数
步骤2：计算台词朗读时间 = 字数 ÷ 3.5（中文约3-4字/秒）
步骤3：计算画面填充时间 = 本场总时长 - 台词朗读时间（本场总时长由叙事决定，Seedance约束4-15秒）
步骤4：将画面时间分配给非台词镜头（反应镜头、环境镜头、特写）
步骤5：验证 台词时间 + 所有镜头时间 = 本场总时长，且落在4-15秒内
```

---

## 切分触发条件

| 情况 | 处理 |
|------|------|
| 台词量计算后 > 15秒 | 在台词自然停顿处拆分 |
| 4秒 ≤ 台词量计算后 ≤ 15秒 | 时长符合要求，用画面填充补足到本场总时长 |
| 台词量计算后 < 4秒 | **告知编剧需要延展内容**，不合并场次 |
| 无台词场次 | 按节奏类型决定镜头数量（静=极少/1-2镜，缓=少/2-3镜，急=中/3-4镜，快=多/4-6镜） |

---

## 节奏与镜头数量关系（无台词时参考）

| 节奏类型 | 特征 | 镜头数量倾向 |
|---------|------|------------|
| 快 | 对话密集、多角色、多动作 | 多镜头、短镜头、快切 |
| 急 | 单人连续施压、短句重复 | 镜头中等、节奏急促 |
| 缓 | 情绪铺垫、单人独白 | 镜头少、长镜头停留 |
| 静 | 关键转折、无台词/少台词 | 极少镜头、单镜头延长、定格 |
| 张力 | 情绪高点、余韵收束 | 极简、远景收束 |

---

## 工作流定位

```
用户发送单集剧本
      ↓
AI读取剧本内容
      ↓
AI按场次划分方法论切分场次（4-15秒为Seedance约束，非硬性统一时长）
      ↓
输出：场次表（编号 | 台词字数 | 台词时长 | 画面时长 | 总时长 | 出场角色 | 节奏）
      ↓
用户确认/调整场次划分
      ↓
AI输出镜头规划表（逐场逐镜头规划）
      ↓
用户确认
      ↓
AI输出分镜脚本
```

---

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 把场次时长当成Seedance镜头约束 | Seedance约束针对场次（生成单元），镜头时长由叙事决定 |
| 合并短场次来"适配"Seedance | 时长<4秒的场次→告知编剧延展内容，不合并 |
| 场次划分由编剧决定 | 场次划分是导演/AI的职责，基于剧本内容分析 |
| 跳过镜头规划直接做宫格图 | 必须先有镜头规划表，再生成宫格图 |

---

## 场次表输出格式

| 字段 | 说明 |
|------|------|
| 场次编号 | C1, C2, C3... |
| 台词字数 | 本场所有台词的总字数 |
| 台词时长 | 台词字数 ÷ 3.5 |
| 画面时长 | 本场总时长 - 台词时长 |
| 总时长 | 本场总时长（由叙事节奏决定，Seedance约束4-15秒） |
| 出场角色 | 本场出场人物 |
| 节奏 | 静/缓/急/快/张力 |
| 叙事内容 | 一句话概括本场发生什么 |
