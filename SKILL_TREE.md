## 二、技能详解

### 技能1：ai-drama（总控）
- **文件**：`skills/ai-drama/SKILL.md`
- **职责**：流水线调度，协调五个专业工种
- **输入**：用户剧本
- **输出**：调度指令
- **状态**：✅ 完整

### 技能2：ai-drama-script（编剧）
- **文件**：`skills/ai-drama-script/SKILL.md`
- **职责**：剧本 → 视频脚本 + 结构化数据
- **输入**：原始剧本
- **输出**：
  - 视频脚本（含镜头切换、动作补充、情绪标注）
  - 角色表
  - 场景表
  - 场次表（每场固定15秒）
  - 风格锁定
- **状态**：✅ 完整

### 技能3：ai-drama-character（角色设计）
- **文件**：`skills/ai-drama-character/SKILL.md`
- **职责**：角色卡 + 定妆照
- **输入**：角色表 + 风格锁定
- **输出**：
  - 角色卡（基本信息、外观锚点、变装）
  - 六视图定妆照提示词
  - 服化道提示词
- **状态**：✅ 完整
- **关键约束**：
  - 图生图 > 文生图（角色一致性靠参考图）
  - 服装参考图必须俯视平铺

### 技能4：ai-drama-scene（场景设计）
- **文件**：`skills/ai-drama-scene/SKILL.md`
- **职责**：场景卡 + 场景图
- **输入**：场景表 + 风格锁定
- **输出**：
  - 场景卡（环境描述、视觉要素、角度索引）
  - 大场景全景图prompt
  - 多角度场景图prompt
- **状态**：✅ 完整
- **关键约束**：
  - **场景图必须为空场景，禁止出现故事角色**
  - 两阶段：文生图大场景 → 图生图多角度

### 技能5：ai-drama-storyboard（分镜导演）
- **文件**：`skills/ai-drama-storyboard/SKILL.md`
- **职责**：分镜编排 + 各类prompt
- **输入**：视频脚本 + 角色卡 + 场景卡 + 风格锁定
- **输出**：
  - 分镜图prompt（每格）
  - 视频prompt（Seedance 2.0格式）
  - 音效prompt
  - 台词prompt（TTS用）
- **状态**：⚠️ 完整但有卡点
- **关键约束**：
  - 每个片段固定15秒
  - 分镜图/视频prompt/音效prompt/台词prompt四者时间轴对齐

### 技能6：ai-drama-audio（音频设计）
- **文件**：`skills/ai-drama-audio/SKILL.md`
- **职责**：三层音频方案
- **输入**：视频脚本 + 分镜方案 + 风格锁定
- **输出**：
  - 台词/TTS脚本（含时间轴）
  - 音效设计审查
  - BGM提示词
- **状态**：✅ 完整
- **关键约束**：
  - 三层音频时间轴对齐
  - 对话段BGM压低

## 三、已知卡点

### 卡点1：分镜时序图（阶段4）

**问题**：
- 即梦生成的时钟标注不可控（"11:91"等）
- 多角色+多场景在同一张图AI混乱
- 即梦Agent模式效果优于CLI，但CLI无法调用

**现状验证**（2026-04-16）：
- 3镜头横向排列较稳定，4个以上质量下降
- 时间标注依赖AI随机，无法精确控制
- Agent模式prompt已验证可生成专业分镜图

**可能的解决方案**：
1. 逐镜生成 → 后期拼接
2. 放弃图生图，用详细文字分镜脚本
3. 研究即梦Agent模式的prompt结构，看能否CLI调用

### 卡点2：Python后端 vs Skill职责边界

**现状**：
- `apps/ai-drama/` 有完整的Python后端（adapters/agents/orchestrator）
- Skill是提示词工程，通过agent调度
- 两者都调用相同的外部工具（dreamina/veo/tts）

**问题**：
- 存在职责不清的情况
- Skill中描述的自动生成流程与Python后端的实现可能重复

**建议**：
- 明确Skill负责"说什么"，Python后端负责"怎么做"
- 当前优先使用Skill模式（因为有即梦Agent验证成功的经验）

## 四、技能间依赖关系

```

    ├──→ ai-drama-character（需要角色表）
    ├──→ ai-drama-scene（需要场景表）
    └──→ ai-drama-storyboard（需要视频脚本+角色卡+场景卡）
            └──→ ai-drama-audio（需要视频脚本+分镜方案）

ai-drama（总控，协调所有阶段）
```
