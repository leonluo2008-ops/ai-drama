# 六视图 Prompt 模板

## 用途
角色定妆照六视图生成时使用。脚本从本文件加载内容，组织后提交给 Dreamina。

## 模板内容

### 必须包含的六个视角
1. 人物面部正面特写
2. 人物面部45度侧面特写
3. 人物面部背面特写
4. 人物正面全身照
5. 人物45度侧面全身照
6. 人物背面全身照

### 约束条件
- 纯白色背景
- 不要出现任何文字
- 人物穿着指定的服装（单图六视图时：保持参考图服装；双图六视图时：参考服装图）
- 只输出成一张图片

### 调用方式
```python
# 脚本加载本文件内容，组装成图生图 prompt
# 图片1 = 面部参考图（face_path）
# 图片2 = 服装参考图（outfit_path）
# prompt 结构：参考图生图 + 六个视角描述 + 约束条件 + 服装引用
```

### 英文 Prompt 组织原则
模型根据上述中文框架组织英文 prompt，确保：
- 六个视角全部覆盖
- 白色背景约束明确
- 服装从第二张参考图继承
- 语气简洁专业（Dreamina 风格）
