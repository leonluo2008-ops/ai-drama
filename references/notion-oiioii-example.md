# Notion参考：OiiOii分镜视频生成示例

> 来源：https://www.notion.so/Oii-341a3f9269aa805e8cf2e254dde49425
> 类型：Seedance 2.0 分镜→视频完整示例

---

## 整体工作流

```
1. 剧本转视频脚本（场景级别的详细描述）
2. 生成角色卡（外观描述 + 角色定妆图）
3. 生成场景固定图（大场景 + 多角度，共两张）
4. 生成分镜宫格图
5. 生成分镜描述（纯文本，含台词和动作）
6. 输出三段式Prompt：
   - storyboardVideoPrompt（画面提示词）
   - storyboardAudioPrompt（音效提示词）
   - storyboardDialoguePrompt（台词提示词）
```

---

## 分镜描述格式

在视频Prompt之前，有一段纯文本的分镜描述：

```
白天 万豪酒店大宴会厅（室内）
沈晚宁（冷冷地看着顾砚，眼神里没有一丝温度）："你不是让我体面点吗？我觉得这身挺好。"
顾砚（冷哼一声，懒得跟她计较）："算了。你妈那边的事，你没去插手吧？"
...
结尾镜头定格2秒，让（内心OS）有余韵，有收束感【重要】
```

**关键要素**：
- 时间/地点标注
- 角色名（动作/表情描述）："台词"
- 内心OS单独标注
- 结尾收束指令

---

## 画面提示词结构（storyboardVideoPrompt）

**按时间轴分段，每段包含**：
- 景别 + 角度
- 角色外观全称（每段都重复完整外观）
- 动作/微细节
- 运镜描述
- 环境/光影细节

**示例**：
```
0-1.6s：近景侧角双人同框，黑色长发、身着白色灯笼袖上衣和深色半身裙的女性站得笔直，目光冰冷直刺对面，嘴唇几乎不带情绪地吐出话，镜头缓慢推近压缩两人距离，背后红金吊灯与宴会人潮虚化成晃动光斑。
1.6-3.2s：过肩中近景落在墨绿色短发穿着深色西装的男人的脸，他冷哼后下颌一抬...
```

**关键规律**：
- 每段1-3秒，精确到小数点
- 角色用外观全称（不使用名字）
- 时间节点与台词/音效完全对齐
- 运镜描述用专业术语（推近/侧移/环绕/甩向/推拉）
- 每段都有光影/环境细节

---

## 音效提示词结构（storyboardAudioPrompt）

**按时间轴分段，每段包含**：
- 空间层次（近/远/前景/背景）
- 主要声源
- 声学细节

**示例**：
```
0～5.8s：近距离低声对话为主，背景维持宴会厅人群谈笑底噪与杯盘轻碰声。
5.8～6.7s：手表轻触与表带摩擦声突出一次，甩向入口时带到远处门口的闷响与厅堂回声。
...
13.0～15.0s：结尾两秒把人声再压低，留住远处模糊声浪与厅堂回声作收束。
```

---

## 台词提示词结构（storyboardDialoguePrompt）

**格式**：
```
X.X～Y.Ys：【角色外观全称】："台词内容。"
```

**内心OS**：
```
X.X～Y.Ys：【旁白（角色外观全称的os）】："内心独白。"
```

---

## 角色外观描述方式

**角色不使用名字，使用完整外观描述**：

| 角色 | 外观全称 |
|------|---------|
| 沈晚宁 | 黑色长发、身着白色灯笼袖上衣和深色半身裙的女性 |
| 顾砚 | 墨绿色短发穿着深色西装的男人 |

角色卡中有独立的prompt：
```
Young man, cold narrow dark eyes, short neat black hair, charcoal grey tailored suit, crisp white shirt, silver silk tie, silver wristwatch, black leather shoes
```

## 与当前Skill的差异

| 对比项 | OiiOii示例 | 当前Skill |
|--------|-----------|----------|
| 视频Prompt时间粒度 | 精确到0.1秒 | 按叙事阶段粗分 |
| 角色指代 | 每段重复完整外观 | 全局声明一次 |
| 运镜描述 | 专业术语+具体动作 | 较笼统 |
| 结尾收束 | 明确标注"定格2秒余韵" | 未明确 |
| 分镜描述 | 独立的纯文本层 | 无此层 |
| 音效空间层次 | 明确近/远/前景切换 | 较简单 |
