# Stage-1 参考：编剧

## 输入

用户原始剧本（纯文本小说/脚本）

## 核心任务

将纯文字剧本视觉化，拆分为：
1. 视频脚本（含镜头切换、动作补充、情绪标注）
2. 角色表
3. 场景表
4. 场次表（每场15秒）
5. 风格锁定

## 视频脚本转化规则

### 场景划分
- 根据物理位置变化划分场景（场景1、场景2...）
- 每个场景标注地点
- 同一物理空间内的连续对话保持在一个场景内
- 电话戏标注为"XX地点 / YY地点（电话交替）"

### 镜头切换标注
- 用【画面切至：XX】标注每次镜头切换的目标
- 电话戏自动采用双机位交替切（说话人/听话人）
- 场景转换时标注新场景的环境描写

### 角色动作补充
- 为每句台词补充对应的肢体动作、表情变化
- 动作必须服务于情绪表达（愤怒→握拳/站起，绝望→跌坐/垂手）
- 关键道具的使用要有特写描写

### 环境视觉化
- 将笼统的场景描述扩展为具体的视觉元素（材质、光影、色调、陈设）
- 每个新场景首次出现时要有环境全景描写
- 光照和氛围要与情绪匹配

### 情绪标注
- 每句角色台词前标注当前情绪状态
- 内心独白明确标记为"内心OS"
- 情绪变化要有过渡，不能突然跳变

### 对话处理
- 保留所有原始台词，不删减不改写
- 散文/旁白转化为画面可表现的内容
- 区分可说出口的台词和内心独白

### 节奏控制
- 高情绪冲突段：快切、短句
- 回忆/情感段：慢下来、增加环境描写
- 结尾：定格、余韵

## 场次表时长约束

**每场固定15秒。**

切分原则：
1. 统计台词字数（中文约3-4字/秒，取中值3.5）
2. 计算台词朗读时间 = 字数 ÷ 3.5
3. 计算画面填充时间 = 15秒 - 台词朗读时间
4. 超过15秒：在台词自然停顿处拆分
5. 不足15秒：用环境镜头/角色反应/特写填充

## 角色表格式

| 字段 | 说明 |
|---|---|
| 角色名 | 原剧本中的名字 |
| 身份 | 主角/配角/反派等 |
| 外观描述 | 详细的外貌描述，供后续阶段使用 |
| 阶段变装 | 是否有变装/换装 |
| 出场场景 | 在哪些场景出场 |

**外观描述规范**：
- 必须包含：发型发色、核心服装、标志性道具
- 描述要具体到AI能理解的程度（不说"很漂亮"，说"黑色长发、白色衬衫、深蓝色半身裙"）

## 场景表格式

| 字段 | 说明 |
|---|---|
| 场景名 | 简洁的场景名称 |
| 地点 | 具体位置描述 |
| 时间 | 白天/夜晚/黄昏等 |
| 关键视觉元素 | 场景中重要的物品、光影、色调 |
| 色调/氛围 | 与整体风格锁定一致 |

## 风格锁定格式

```
🎨 视觉风格锁定
- 来源：从剧本推断 / 用户指定
- 画风：[如 吉卜力风格 / 写实 / 油画质感]
- 色调体系：主色 + 辅色 + 对比色
- 质量规格：分辨率 + 帧率 + 渲染风格
- 特效方向：
- 构图偏好：
- 竖横比：[9:16 竖屏 / 16:9 横屏]
```

**风格锁定一旦确定，后续所有阶段必须遵守，不可修改。**

## 输出格式模板

```markdown
## 视频脚本

### 场景1：[地点]
[视频脚本正文，含镜头切换标注、动作补充、情绪标注]

### 场景2：[地点]
...

---

## 结构化数据

### 角色表
| 角色 | 身份 | 外观描述 | 阶段变装 | 出场场景 |

### 场景表
| 场景 | 地点 | 时间 | 关键视觉元素 | 色调/氛围 |

### 场次表
| 场次 | 所属场景 | 时长 | 出场角色 | 节奏 | 节奏原因 |

### 风格锁定
[风格锁定摘要]
```
