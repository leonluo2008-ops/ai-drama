## 关键教训（2026-05-20 实测）
1. **下载目录共享 bug**：4角色共用 `/tmp` 导致图片互相覆盖 → 各角色独立目录
2. **cross-device rename**：路径跨设备时报 `Invalid cross-device link` → `shutil.copy2` + `unlink`
3. **--images 参数格式**：必须用 `--images=path`，空格分隔会报 unknown command
4. **发图前验证**：必须 vision 分析本地文件再发用户，不能只看 dreamina 后台
5. **风格外置**：`style.md` 定义 art_direction，脚本动态加载，不硬编码在 prompt
