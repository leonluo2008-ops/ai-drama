# Stage-5 参考：音频设计

## 输入

- Stage-1产出的视频脚本
- Stage-4产出的分镜方案（含时间轴）

## 三层音频架构

```
层1：旁白 + 角色台词  → 用户用 MiniMax TTS 生成
层2：音效             → 已写入 Seedance 视频Prompt（Stage-4产出）
层3：背景音乐(BGM)    → 用户用 MiniMax Music 2.6 单独生成
```

**本Stage负责层1和层3，层2只做审查。**

## 层1：TTS台词脚本

### 台词时间轴格式

```markdown
## 台词时间轴

### 场次[N]：[标题]

0.2～1.6s：【角色外观全称】："台词内容。"
1.6～3.2s：【角色外观全称】："台词内容。"
8.6～10.0s：【旁白（角色外观全称的os）】："内心独白。"
```

### TTS参数建议

| 参数 | 说明 |
|---|---|
| 角色 | 外观全称 |
| 情绪 | 愤怒/悲伤/平静/嘲讽/焦急等 |
| 语速 | 正常/加快/放慢 |
| 音色建议 | 根据角色性格推荐 |

**情绪标注继承自Stage-1的视频脚本。**

### 规则
- 角色指代使用外观全称（与视频Prompt一致）
- 旁白标注(os)表示内心独白
- 时间轴必须与Stage-4的时间轴严格对齐

## 层2：音效审查

检查Stage-4产出的音效Prompt是否完整：

**音效设计原则**：
- 明确空间层次：近/远、前景/背景
- 使用声学动词：虚化、闷响、回声、摩擦声、掠过、压低、突出
- 区分声源类型：环境底噪、Foley（脚步/衣料/杯盘）、人声掠过
- 收束时压低环境音，留出空间回响作余韵

**如发现遗漏**：补充输出缺失的音效Prompt。

## 层3：BGM提示词

### 整体BGM策略

```markdown
## BGM方案

### 整体策略
- 基调：[如"弦乐主导，钢琴点缀，都市情感风格"]
- 情绪弧线：[如"平静→紧张→爆发→余韵"]
- 总时长：[N秒]
- 参考风格：[如"韩剧OST / 日系动漫配乐 / 史诗电影配乐"]
```

### 分段BGM提示词格式

```markdown
### BGM-A：[段落名]（0s–Xs）
- 情绪：[关键词]
- 乐器：[主要乐器]
- 节奏：[快/中/慢]
- 参考描述：[如"类似XXX的风格"]
- Music 2.6 Prompt：[可直接使用的音乐生成prompt]
```

### BGM与画面配合规则

| 场景 | 配合方式 |
|---|---|
| 对话段 | BGM压低，不干扰台词 |
| 情感段 | BGM渐强，烘托情绪 |
| 高潮段 | BGM爆发，与画面节奏同步 |
| 收束段 | BGM渐弱，留白余韵 |
| 场景转换 | BGM过渡或切换 |

## 输出格式

```markdown
## 音频设计方案

### 层1：台词/TTS脚本
[台词时间轴 + TTS参数]

### 层2：音效审查
[审查结果 + 补充音效（如有）]

### 层3：BGM方案
[整体策略 + 分段prompt]
```

## 注意

- 三层音频的时间轴必须严格对齐
- **每个视频片段固定15秒**，台词/音效/BGM时间轴与之对齐
- BGM不能喧宾夺主，台词段必须压低
- TTS音色建议要区分角色，不能所有角色用同一个声音
