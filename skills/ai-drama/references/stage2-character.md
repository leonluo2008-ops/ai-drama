# Stage-2 参考：角色设计

## 输入

- Stage-1产出的角色表
- Stage-1产出的风格锁定

## 核心原则

**图生图 > 文生图**。角色一致性不靠Prompt文字描述，而靠参考图。

## 定妆照生成流程

### 需要准备的参考图（每个角色2张）
1. **面部参考图**：人物面部/形象
2. **服装参考图**：完整穿搭（上衣+下装+鞋+配饰+道具），俯视平铺，不裁切

### 如用户无参考图→先生成参考图

**步骤1：生成面部图（文生图）**
```
{prompt: [角色外观描述], portrait photo, neutral expression, clean solid color background, studio lighting, high detail}
```

**步骤2：生成服装参考图（文生图，必须俯视平铺）**
```
{prompt: [完整穿搭描述，包含上衣、下装、鞋、配件、道具等所有穿戴物]，
纯白色背景俯视平铺，所有物品完整展示不裁切，每件物品保持完整轮廓和细节，
clean white background, top-down flat lay, all items fully visible, detailed fabric texture, high detail。}
```

**⚠️ 服装参考图禁止关键词**："真人穿戴"、"模特穿着"、"model"、"figure"、"穿戴效果"——会导致生成真人穿戴照而非平铺图。

**步骤3：图生图生成六视图定妆照**
```
参考图生图：请严格根据图片1中的角色，生成一张人物的六视图角色定妆照；
不要出现文字，要求纯白色背景，有人物面部正面特写、人物面部45度侧面特写、
人物面部背面特写、人物正面全身照、人物45度侧面全身照以及人物背面全身照。
该人物穿着图片2中的服饰。注意：只输出成一张图片。
```

## 服化道提示词格式

每个角色需输出三段式服化道提示词：

**妆容**：
```
妆容：[底妆类型]，[眼妆细节]，[眉形]，[唇色]，[腮红位置]
```

**发型**：
```
发型：[造型]，[刘海]，[发色]，[发丝质感]
```

**造型**（必须包含全部五项）：
```
造型：[上衣]，[下装]，[鞋]，[配饰]，[道具（如有）]
```

## 角色卡格式

```markdown
## 角色卡：[角色名]

### 基本信息
- 身份：
- 性格：

### 角色外观全称（用于所有Prompt中指代角色）
[发型发色] + [核心服装] + [性别]
示例：黑色长发、身着白色灯笼袖上衣和深色半身裙的女性

### 全局外观锚点
- 发型/发色：
- 眼睛：
- 核心服装：
- 标志性道具/武器：

### 参考素材清单
| 素材 | 用途 | 状态 |
|---|---|---|
| 人物面部图 | 图生图输入1 | 用户上传/待生成 |
| 服装参考图 | 图生图输入2 | 用户上传/待生成 |
| 六视图定妆照 | 分镜参考图 | 待生成 |

### 服化道提示词
#### [版本名，如"日常职场妆"]
[完整的三段式服化道描述]
```

## 角色指代规则

- 所有Prompt中不使用角色名字，使用外观全称
- 首次出现写完整全称，同一Prompt内后续可用简短指代（"该女性"、"该男人"）
- 跨Prompt必须重新写全称

## 脚本调用

生成定妆照时调用：
```bash
python scripts/dreamina_generate.py \
  --type character \
  --project "{项目名}" \
  --character "{角色名}" \
  --face_prompt "{面部Prompt}" \
  --outfit_prompt "{服装Prompt}" \
  --ratio 1:1
```

图片下载后立即归档到：
```
projects/{项目名}/02-characters/{角色名}_{图片类型}.png
```
