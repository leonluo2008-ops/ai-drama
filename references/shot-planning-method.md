# 镜头规划方法论

## 问题现象
直接拿场次表去做宫格图，跳过了镜头设计环节，导致分镜质量粗糙、镜头语言混乱。

## 根因
场次表只解决了"切成几块、每块多少秒"，但没有解决"每块里用哪些镜头来讲述这个故事"。

## 缺失的中间步骤
```
剧本 → 场次表（按时长切分）→ 【这里缺：镜头规划表】→ 宫格图生成
```

## 「镜头规划表」需要决定什么

### 1. 叙事功能层（这场戏要达成什么）
- 核心冲突是什么
- 观众应感受到什么情绪
- 谁是主导者，谁是承受者

### 2. 镜头设计层（怎么用镜头讲故事）
- 这场戏需要几个镜头
- 每个镜头的**景别**（远景/全景/中景/近景/特写）
- 每个镜头的**角度**（平视/俯视/仰视/侧拍）
- 每个镜头的**运镜**（固定/推/拉/摇/移/跟）
- 每个镜头的**画面内容**（谁在画面里，在做什么）

### 3. 对话处理层（台词怎么对应镜头）
- 台词由谁说出 → 哪个镜头承接
- 说话时镜头切到谁 → 反应镜头
- 关键台词是否需要特写放大

## 已确认结论

1. **粒度**：每个场次按节奏灵活决定镜头数量，不固定
2. **表达形式**：纯文字
3. **谁来设计**：AI全自动生成，用户只确认

## 镜头规划表字段（定稿）

| 字段 | 说明 |
|---|---|
| 镜头编号 | 例如 C3-S1（第3场第1个镜头） |
| 时间范围 | 例如 0-2s / 2-5s |
| 景别 | 远景/全景/中景/中近景/近景/特写/大特写 |
| 运镜/运动 | 固定/跟拍/横移/推/拉/摇/甩/快速横移切角/镜头微晃 |
| 画面内容 | 具体描述（谁+做什么+表情/动作/与他人关系+场景细节） |
| 角色标注 | @角色名 或 @图N |
| 台词承接 | 这段时间范围内的台词（可无） |

## 节奏与镜头数量关系

| 节奏类型 | 特征 | 镜头数量倾向 |
|---|---|---|
| 快 | 对话密集、多角色、多动作 | 多镜头、短镜头、快切 |
| 急 | 单人连续施压、短句重复 | 镜头中等、节奏急促 |
| 缓 | 情绪铺垫、单人独白 | 镜头少、长镜头停留 |
| 静 | 关键转折、无台词/少台词 | 极少镜头、单镜头延长、定格 |
| 张力 | 情绪高点、余韵收束 | 极简、远景收束 |

## 镜头描述格式

```
[时间范围]：
[景别][运镜/运动方式] [具体画面内容]
```

示例：
- `远景广角掠过宴会厅，水晶吊灯冷光压下来...`
- `中景跟拍@图3一路小跑挤进人群，肩膀撞开人影，镜头微晃制造慌乱感`
- `切到中近景对峙，镜头在两人之间快速横移来回切角`
