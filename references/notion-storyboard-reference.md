## 关键洞察（对Skill的参考价值）

### 1. 九宫格分镜的结构化组织方式
- 按**时间行**分组：每行3格 = 5秒
- 3行×3格 = 15秒视频
- 每行有明确叙事功能：起势→冲突→余韵

### 2. Prompt分层结构
- **环境设定(Context)**：场景+氛围，全局声明
- **角色设计(Character)**：主角特征描述，全局声明
- **剧情流转(Story)**：按Panel逐格填写，含景别标注
- **风格修饰(Style Modifiers)**：技术增强词，全局追加

### 3. 每格描述格式
```
Panel [N] (景别/功能)：[具体画面描述]
```

### 4. 与当前Skill的差异
| 对比项 | Notion案例 | 当前Skill |
|--------|-----------|----------|
| 宫格结构 | 3×3固定九宫格 | 按需2-9格 |
| 时间分配 | 每行5秒固定 | 按台词字数动态计算 |
| Prompt层次 | 环境→角色→剧情→风格 | 风格锁定→各格描述 |
| 景别标注 | 每格标注景别+功能 | 每格标注景别+运镜 |
| 画幅控制 | --ar 16:9 | 待解决（方案A不可控） |

### 5. 提炼出的方法论
已整理到 `storyboard-methodology.md`：
- 方法1：Prompt分层架构（全局声明 + 逐格差异 + 尾部修饰）
- 方法2：叙事行分组（起势→冲突→余韵）
- 方法3：每格精简格式（Panel N + 景别/功能 + 画面描述）
