# 角色差异化设计方法论

> 实测教训总结：2026-05-21 鸭子角色设计

## 核心问题

**同一参考图生成多个角色，结果必然相同或高度相似。**

原因：参考图驱动的是「物种+风格+核心特征」，图生图会继承参考图的所有视觉元素，包括颜色、配饰等差异化维度。

## 角色差异化维度

| 维度 | 示例 | 能否靠参考图继承 |
|------|------|----------------|
| 物种 | 鸭子 vs 兔子 | ❌ 需独立参考图 |
| 风格 | 写实 vs 卡通 | ✅ 可继承 |
| 服装颜色 | 黄色安全帽 vs 蓝色安全帽 | ❌ 需独立参考图或手动编辑 |
| 面部特征 | 眼睛颜色、发型 | ❌ 需独立参考图或独立文生图 prompt |
| 配饰 | 安全帽 vs 棒球帽 | ❌ 需独立参考图 |

## 可行的角色拓展方案

### 方案A：每个角色独立参考图（推荐）

```
托比参考图（黄色安全帽） → 托比角色图
莱恩参考图（蓝色安全帽） → 莱恩角色图
```

**优点**：最可靠，差异化明确
**缺点**：需要用户或创作提供多张参考图

### 方案B：独立文生图 prompt

```
托比：物种+颜色+配饰描述（参考图特征）
莱恩：同物种+不同颜色/配饰描述
```

**注意**：需要 prompt 锚定风格，否则两个角色可能风格不一致
**示例**：
```
托比：minion style male, yellow skin, black short hair, brown eyes...
莱恩：minion style male, yellow skin, ORANGE hair, GREEN eyes...（差异化）
```

### 方案C：手动编辑参考图

用 PS/图像编辑工具把参考图中的配饰颜色/样式改成另一个版本，作为第二个角色的参考图。

**示例**：托比黄色安全帽 → PS 改成蓝色安全帽 → 作为莱恩参考图

**优点**：保持风格完全一致
**缺点**：需要人工介入

### 方案D：不同物种 + 同一风格

```
托比：白色卡通鸭子（黄色安全帽）
莱恩：白色卡通兔子（黄色安全帽）→ 不同物种自然差异化
```

**优点**：差异化明显
**缺点**：不一定符合故事设定

## 决策树

```
收到多个角色的生成需求
  ↓
用户提供了 N 张独立参考图？
  ↓ 是 → 每个角色用各自的参考图（方案A）
  ↓ 否
    ↓
  是否有明确的风格锚定（如 minion style）？
    ↓ 是 → 方案B：文生图 + 风格锚定 + 差异化 prompt
    ↓ 否
      ↓
    能否手动编辑参考图？（方案C）
      ↓ 是 → 方案C
      ↓ 否
        ↓
      不同物种是否可行？（方案D）
        ↓ 是 → 方案D
        ↓ 否 → 返回用户：需要更多参考图或明确差异化要求
```

## SKILL.md 脚本能力边界

当前 `dreamina_generate.py` 的 `--face_image` 和 `--face_prompt` **互斥**，不支持：

```
--face_image <参考图> --face_prompt <差异化描述>  # 不支持
```

如需此能力，需扩展脚本支持参考图驱动服装 + prompt 驱动面部差异化的组合模式。

## 经验规则

1. **同一参考图 = 同一角色**：不要期望 AI 自动对同一参考图做差异化处理
2. **风格锚定 > 自由发挥**：文生图时明确风格词（如 minion style）比不加风格词更可靠
3. **配饰颜色是最容易的差异化**：发型/眼睛颜色容易被风格吞噬，配饰颜色更稳定
4. **差异化越具体越可靠**：「橙色头发」比「不同发型」更稳定，因为描述更具体
